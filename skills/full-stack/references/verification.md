# 验证与交付

根据实际变化与失败成本选择检查，交付时明确结果证据。本节用于决定验证范围，不要求每次执行全部测试，也不要求为文案或低风险整理补造测试。

## 验证什么

| 改动或风险 | 合适的验证 |
| --- | --- |
| 新建工程或依赖、构建配置变化 | 依赖安装可复现、格式与静态检查、类型检查、构建，以及从真实构建产物启动 |
| 独立业务规则或输入校验 | 规则行为测试，覆盖允许与拒绝的输入，不断言内部实现步骤 |
| 事务、幂等、revision、约束或迁移 | 隔离的真实 PostgreSQL 测试，验证并发、回滚、重复执行、历史数据与迁移兼容性 |
| HTTP、认证或新增 MCP | 权限、状态码、允许公开的字段及错误脱敏；有多协议时验证同一操作的业务结果一致 |
| 页面关键操作 | Playwright 等浏览器回归，验证核心流程、失败反馈、草稿保护与键盘操作；视觉探索补充检查布局与交互 |
| 文件、后台任务或外部调用 | 传输与确认的部分失败、重复调用、授权过期、任务取消与重试；测试替身和真实服务验收分开 |
| 容器、代理与发布流程 | 构建镜像、生产入口、健康检查、SPA/API 路由、鉴权头转发、隔离和更新失败后的恢复 |

优先沿用项目已有测试工具；新项目可采用 Vite+ 的测试入口和 Playwright。命令参数以目标项目当时的文档为准。新项目才使用 [默认名字与形状](defaults.md) 里的脚本名，不假定已有项目用了同名脚本。涉及架构约束时可增加依赖边界检查，但文本匹配不能冒充完整语义分析。

数据库测试不能只用内存替身证明事务正确。迁移至少验证空库初始化、已有数据升级、重复执行及失败后状态；数据操作验证真实并发冲突。安全相关的响应还要确认没有暴露内部字段。

检查通过后继续交付；只有新改动、失败或未解决风险才扩大或重复验证，不为凑检查数量运行无关测试。

## 测试资源的边界

使用专门的测试连接和随机隔离库、对象前缀、容器网络、临时浏览器资料。为本次运行记录资源身份，只清理本次创建的资源；现有数据库、用户文件、私有配置及其他对象不属于缓存。

外部付费或不可逆服务默认使用 tests 内的替身；真实服务验证按当前任务授权执行。替身不进入生产适配器作为失败回退，也不使用实际用户凭据或业务数据制作 fixture。

数据库、浏览器或云服务条件缺失导致跳过时，报告缺失条件与未覆盖行为。部分测试成功而其他测试被跳过，不能汇总为“全部通过”。清理失败要保留本次资源标识并说明处理范围，不能扩大删除范围补救。

## 发布验证分层记录

按层留下证据。本地端到端记录业务链路；容器验收记录 Linux 进程、代理和隔离；真实环境记录 DNS、公开 HTTPS、SSH、GHCR 拉取、数据库网络与权限、对象存储 IAM/CORS，以及实际启用的备份恢复和监控。只对使用到的服务记录。操作步骤见 [部署与恢复](deployment.md)。

没有访问权限或未获得执行授权时交付配置与待验证项，不把它们标记为已完成。某一层通过不能写成其他层已验证。

## 文档与交付内容

文档与实现保持一个事实来源。小项目可在 README 中完成说明；内容增长后按职责拆入文档，只有需要独立站点时才引入 VitePress。已有文档体系优先沿用。

- **运行说明**：安装条件、实际启动命令、配置示例、数据库初始化、必要的本地验证入口。前端公开构建配置与后端私有运行配置分别说明。
- **架构与接口**：模块职责、重要边界及偏离默认方案的理由；接口文档尽量从定义生成，避免复制维护多份字段说明。架构图需要可编辑源文件时使用 `illustration`。
- **运维说明**：部署环境、产物来源、发布和迁移顺序、状态与日志入口、回退条件、数据库恢复及未完成的云端准备。
- **工程约束**：仅把项目需要持续遵守的约定写入 AGENTS.md，例如依赖方向、迁移规则、必要测试与注释要求，不把整份技能复制到项目。

文档示例使用通用名称和明确占位配置；没有运行的命令只能作为操作说明，不能作为成功证据。变更路径或入口后检查相关链接；启用文档站时再执行其构建与必要页面检查。

最终回复概括已完成成果、关键取舍、实际验证及仍影响使用的条件，链接到真实文件或结果。已有部署记录需区分应用版本、迁移状态与当前健康状态；失败发布不能因为留下了版本文件就视为成功。
